# ✨ To‑Do List App

A simple and stylish To‑Do List application built with **HTML, CSS, JavaScript, and Bootstrap**.  
It supports adding, completing, deleting, undoing tasks, clearing all tasks, dark/light mode toggle, and progress tracking.

---

## 🚀 Features
- Add new tasks
- Mark tasks as completed ✅
- Delete tasks 🗑️
- Undo last deleted task 🔄
- Clear all tasks ❌
- Dark/Light mode toggle 🌙☀️
- LocalStorage persistence 💾
